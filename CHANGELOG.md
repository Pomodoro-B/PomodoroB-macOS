# Changelog

All notable changes to this project will be documented in this file.

## [0.2.0] - 2026-10-09

### Added
- Explicit Dark Mode appearance toggle directly inside Settings.
- Adjustable timer durations for Focus, Short Break, and Long Break configurations.
- Automated `.dmg` packaging script with custom Pomodoro/B drag-and-drop aesthetics.
- Custom exact color palette for Light and Dark modes.

### Fixed
- Addressed timer ring geometry rendering bug where progress was vertically misaligned.
- Fixed the Settings refresh delay where updated durations wouldn't reflect on the main menu instantly.
- Expanded the tiny hit-area constraint on the Settings "Back" button.
- Re-aligned the Auto-Start toggle to sit perfectly flush with the right edge.

## [0.1.0] - Initial Release
- Initial baseline macOS Pomodoro timer logic.
